# Templates

`templates/` holds one skeleton per repeated note form — a trip sheet, a machine-setup
runbook, a race-day checklist. The instances keep only what differs.

Filled-in copies of a shared form sitting in a bucket are the clearest signal the
template was never extracted. That is a maintenance finding as much as a filing one:
notice it during a cleanup round and pull the skeleton out.

## A template is a skeleton, not an example

Headings, prompts, and empty fields, with no content from any instance that produced it.
Deriving a template from a filled-in note means stripping every value, not most of them.

## Why the stripping matters

A template is copied into every note made from it and travels with the vault template
wherever that is shared — a name, an address, a phone number or a licence key left in a
skeleton spreads with it. No check catches a value left in a template; the stripping is
yours to do.
